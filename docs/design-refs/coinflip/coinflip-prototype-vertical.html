RapidClash — coinflip prototype

A real 3D cylinder, not a flat disc. Vertical spin axis. The server picks the result; the coin spins 5–7 turns and eases onto it. Faces never recolour — the outcome lives only in where the rotation stops.

Tap a button to flip
What this proves against the four problems:
  • Round at rest — a real cylinder face is a perfect circle, always.
  • Thickness mid-flip — the cylinder's edge has real width; you see it every time the coin turns edge-on.
  • Two-tone edge — that light/dark banding on the rim is one light source on a curved surface. It's automatic, not hand-placed.
  • No leak — gold and silver alternate the whole spin; you can't tell the result until it settles.
  • Feels like chance — random turn count each flip + ease-out deceleration. Motion blur tracks spin speed (a CSS blur, near-free).
